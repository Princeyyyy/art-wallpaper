# Security Policy

## Supported Versions

Security updates are actively provided for the latest minor and patch versions of Art Wallpaper:

| Version | Supported |
| ------- | --------- |
| 4.1.x   | Yes       |
| 4.0.x   | No        |
| < 4.0   | No        |

---

## Reporting a Vulnerability

We take the security of Art Wallpaper and user privacy seriously. Art Wallpaper runs locally as a native desktop client and does not collect or transmit personal user data.

If you discover a security vulnerability or sensitive flaw:

1. **Do not create a public GitHub issue.**
2. Send an email directly to the maintainer: **[princemumo80@gmail.com](mailto:princemumo80@gmail.com)**.
3. Include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact and affected platforms (Windows/macOS).

### Response Timeline
- You will receive an acknowledgment within **48 hours**.
- A patch or remediation will be developed and released promptly with credit provided in the release notes (unless you prefer anonymity).
